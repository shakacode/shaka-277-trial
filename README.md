# shaka-277-trial

Disposable public fixture for live acceptance checks on
[shakacode/shaka#277](https://github.com/shakacode/shaka/issues/277). Synthetic content only;
safe to delete.

`bin/greet NAME` prints a greeting; `bin/greet --shout NAME` prints it in upper case; `bin/greet --name-first NAME` prints `NAME, hello!`. Run `bin/setup`, `bin/test`, and `bin/validate`.
